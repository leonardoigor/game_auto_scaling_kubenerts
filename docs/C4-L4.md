# C4 – Nível 4: Código

## Protocolo de Mensagens
- `join`: `{ type: "join", payload: { playerId, roomId } }` → gateway responde `assign_room`.
- `assign_room`: `{ type: "assign_room", payload: { roomId, podId } }`.
- `input_move`: `{ type: "input_move", payload: { dir: { x, y } } }` → gateway publica em `room:{id}:in`.
- `input_attack`: `{ type: "input_attack", payload: { angle } }` → worker cria projétil.
- `state_update`: `{ type: "state_update", payload: { roomId, players: [...], projectiles: [...], buffItems: [...] } }`.
- `leave`: remove jogador do estado e do conjunto `room:{id}:players`.

## Estruturas de Estado
- Jogador: `{ x, y, vx, vy, speed, podId, hp, maxHp, dead, killerId, lastAttackTs }`.
- Sala: `{ players: Map<playerId, Player>, projectiles: Array<Projectile>, buffItems: Array<BuffItem>, lastUpdate }`.
- Projétil: `{ x, y, vx, vy, ownerId }`.
- BuffItem: `{ id, x, y, type }`; Buff ativo no jogador: `{ type, expiresAt }`.

## Algoritmos
- Movimento de jogadores: integração por `dt` com clamp ao mundo.
  - Referências: `worker/index.js:96–106`
- Ataque: valida cooldown e empurra projétil com velocidade/ângulo.
  - Referências: `worker/index.js:56–64`
- Física de projéteis: atualiza posição; remove fora da tela; colisão jogador-projétil via distância (`<= 12px`); aplica dano `20%` de `maxHp`; marca morte.
  - Referências: `worker/index.js:107–128`
- Buffs:
  - Coleta: raio 14px; adiciona `{ type, expiresAt = now + 20000 }` ao jogador e remove item do mapa.
    - Referências: `worker/index.js:143–159`
  - Expiração/Respawn: ao expirar, remove do jogador e respawna novo item do mesmo tipo em posição aleatória.
    - Referências: `worker/index.js:78–85`
  - Multiplicadores: `V` velocidade+, `A` ataque+; auras `M` movimento- e `D` ataque- aplicadas a inimigos em 100px.
    - Referências: `worker/index.js:87–125`
  - Payload inclui `players[].buffs` (lista de letras) e `buffItems`.
    - Referências: `worker/index.js:188–196`

### Buffs – Detalhamento dos Efeitos
- `V` (Velocidade+): multiplica a velocidade do jogador por `1.5` por instância (empilhável).
- `A` (Ataque+): multiplica o dano do jogador por `1.5` por instância (empilhável).
- `M` (Movimento-, aura): para cada fonte em um raio de `100px`, multiplica a velocidade dos inimigos por `0.7` (empilhável).
- `D` (Ataque-, aura): para cada fonte em um raio de `100px`, multiplica o dano dos inimigos por `0.7` (empilhável).
- Cálculo do dano com buffs: `damage = floor(base * attUp * attDown)`, com `base = floor(0.2 * maxHp)`, `attUp` produto de `A`, `attDown` produto de `D`.
  - Referências: `worker/index.js:172–176`
- Publicação de estado: por tick e imediatamente após ataque para baixa latência.
  - Referências: `worker/index.js:107–110`, `worker/index.js:140–146`

## Operação
- Kubernetes:
  - Services: `gateway` (NodePort `30080`), `matchmaker` (NodePort `31400`), `redis` (ClusterIP `6379`).
  - Deployments: `gateway`, `worker`, `matchmaker`, `redis`.
  - RBAC: Role/RoleBinding para `matchmaker` operar escala de `gateway`.
- Scripts: `scripts/deploy.ps1`, `scripts/destroy.ps1`.
 - Lifecycle ocioso do `gateway`:
   - Verificação a cada 1s; se `playerCount=0` por 20s, solicita `GET /scaleDown` ao `matchmaker`, remove-se de `pods:active`, marca `pod:{podId}:status=terminating` e encerra (`process.exit(0)`).
   - Referências: `gateway/index.js:168–187`, `matchmaker/index.js:137–140`.

## Observações
- Servidor é autoritativo: vida, morte e projéteis são calculados no Worker; cliente apenas reflete estado e envia inputs.
- Cooldown de ataque impede spam; `leave` remove jogador da visão dos demais.
- Buffs são cumulativos e expirados automaticamente; letras são renderizadas acima da barra de vida; itens respawnam no mapa ao fim do efeito.
